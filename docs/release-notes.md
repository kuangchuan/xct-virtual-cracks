# vn46 — private research snapshot

Image-informed virtual XCT damage generation, paired geometric supervision and material-specific segmentation for Mortar, Recycled-aggregate mortar, GFRP and SiC composite.

This snapshot includes the portable synthesis package, a procedural demonstration, MPS-only neural commands, four original V45 development checkpoints, manuscript visual examples, and the complete five-seed mIoU results for the separate updated-generator real-image adaptation study.

The visual examples retain their V45 model provenance. Table 5 results use a distinct model family and real validation-based selection. The repository reports every run without exclusion and does not claim an independent test or universal annotation savings.

The repository is private. Full source volumes, human masks and large training caches are not bundled. See the README, data-availability notes and frozen study protocol for reproduction scope.
